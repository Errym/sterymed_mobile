# SteryMed — Complete Professional UI/UX Breakdown
## A High-End Dental Clinic SaaS — Screen by Screen, Widget by Widget

---

## Design Philosophy

**Reference language:** Sterily demo (clear nav, large readable tables, short workflows, fast status changes) — but with SteryMed's own identity.

**The one rule:** Every screen answers one operational question in under 3 seconds.

**Visual identity:**
- **Navy header** (`#1A2A5C`) — authoritative, calm, medical-grade
- **Brand primary** (`#1E5BA8`) — actions, links, active states
- **Surface white** (`#FFFFFF`) — cards float on `#F7F9FC`
- **Aging language** — green (fresh) → amber (medium) → red (urgent), applied consistently
- **Typography:** Inter, tight hierarchy (28 / 18 / 16 / 14 / 13 / 12)
- **Radius:** 16px cards, 12px inputs, 999px pills
- **Motion:** 220ms fade+slide for list items, 150ms scale for taps, 300ms for state transitions

```

       ↓

       ↓

       ↓ success → invalidate cache, return result
       ↓ network error → fall through to OUTBOX
       ↓ validation error → rethrow (user sees error)
       ↓
OFFLINE → outbox.enqueue(item)
       ↓
SyncStatusCubit.refreshNow()
       ↓
Return synthetic result (optimistic UI)
       ↓
When online again → SyncEngine.flush()
       ↓
Server processes → outbox.remove(item.id)
```

abstract final class RoleTabs {
